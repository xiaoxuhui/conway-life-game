# 交互与视觉设计

## 1. 设计原则

- **先看懂再操作**：棋盘是视觉中心，控制区不抢占注意力。
- **状态不含糊**：运行/暂停、代数、活细胞数量随时可见。
- **常用操作就近**：开始、单步、清空和随机放在同一主控制区。
- **渐进呈现**：初次打开只暴露常用能力，导入/导出等放入次级区域。
- **操作可预期**：绘制、擦除、载入预设等行为不因细微手势变化而反复切换。

## 2. 页面信息架构

```text
┌──────────────────────────────────────────────────────────┐
│ 康威生命游戏                       状态 · 第 0 代 · 0 个 │
├──────────────────────────────────────────────────────────┤
│ [开始] [单步] [清空] [随机]  速度 [ 5 ] 代/秒（1–1000）│
│ 预设 [选择图案 ▾] [放置]        [导入] [导出]（P1）      │
├──────────────────────────────────────────────────────────┤
│                                                          │
│                      可编辑棋盘                          │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 点击或拖动绘制；拖动从活细胞开始时会擦除。               │
└──────────────────────────────────────────────────────────┘
```

手机端按以下顺序纵向排列：标题与状态、主操作、速度、预设/文件操作、棋盘、提示。棋盘可缩小格子，但主要控件的点击区域不小于约 44 × 44 像素。

速度使用 `number` 输入框：用户可以直接键入，也可以使用原生上下箭头。有效整数即时应用；编辑中的空值暂不改变运行速度，失焦时恢复；小数或越界值在确认时取整并限制到 1–1000。状态区单独显示实际代/秒，便于识别大型世界未达到目标速度的情况。

控制区增加“逻辑代码”输入行，示例占位符包含 `AND(A,B),A=1,B=0` 和 `NOT 1`。点击“生成结构”或在输入框按 Enter 后，对应逻辑门在当前视图中心显示可拖动预览；用户点击观察区确认位置后才追加。下方状态文字显示规范化表达式、预期真值、真实线路数量和实际锁存代数。解析失败时保留原世界并在原位置给出错误原因。

v0.10.0 在帮助文字下增加“我的函数”选择行。选择后点击“载入”把保存的原文填入逻辑代码框，仍需用户主动点击“生成结构”；“保存函数”打开名称确认框；“管理函数”打开可编辑名称和代码的对话框。空库时选择、载入和管理均禁用，但保存按钮会在输入框有内容时启用。删除采用与图案库一致的二次点击确认，所有对话框保留可见错误区和关闭按钮。

v0.11.0 在函数选择行下动态显示输入选择器，每项由变量名和 0/1 下拉框组成。切换函数恢复它保存的默认输入；载入后保留当前选择。保存对话框显示“输入：A、B”，管理时编辑的是不含赋值的函数主体，保存修改后重新识别输入并更新选择器。

## 3. 核心流程

### 首次进入

1. 展示空棋盘，状态为“已暂停”，代数为 0。
2. 棋盘下方提示：“点击或拖动绘制细胞，然后按开始。”
3. “单步”可用；“开始”是唯一的主色按钮。

### 绘制与擦除

1. 指针在一个死细胞上按下，确定本次手势为“绘制”。
2. 拖过的死细胞变活；已处理格子不会被重复翻转。
3. 指针在一个活细胞上按下，则本次手势为“擦除”。
4. 运行时默认禁止编辑棋盘，并提示先暂停，避免用户误解演化结果。

### 平移与缩放

- 鼠标中键或右键拖动平移视野；按住空格再用左键拖动也可平移。
- 轻点空格仍切换开始/暂停；只有发生拖动时才把本次空格操作解释为平移。
- 滚轮以光标所在世界位置为锚点缩放，缩放前后该位置保持在同一屏幕点。
- 单指保持绘制；双指手势同时支持平移和缩放，进入双指手势时取消未完成的单指绘制。
- 运行中允许平移和缩放，但仍禁止改变细胞。
- “适应图案”把当前全部活细胞居中并缩放到可见范围；空世界则回到原点和默认倍率。
- 近距离显示细网格，远距离自动隐藏网格；极远视图使用像素级标记表示活细胞密度。

### 开始、暂停与单步

- 点击“开始”后，按钮变为“暂停”，状态文字同步变化。
- 点击“暂停”只停止演化，不改变当前局面或代数。
- 点击“单步”时保持暂停，并只执行一代。
- 浏览器标签页不可见时自动暂停，防止用户回来后错过大量代数。

### 清空

- 点击“清空”后先暂停，再清空棋盘并把代数归零。
- 棋盘已有内容时显示“已清空 · 撤销”提示；撤销恢复清空前的局面和代数。

### 随机填充

- 点击后先暂停，再按默认密度填充并把代数归零。
- 连续点击会产生新局面；页面明确显示活细胞数量。

### 放置图案（v0.5）

1. 从“内置图案”或“我的图案”选择图案，再点击“放置”。按钮变为“完成”，棋盘显示半透明预览。
2. 移动鼠标或按住左键拖动预览；松开或单击把图案追加到目标位置。放置后仍保留预览，可继续放置多个副本。
3. 点击“旋转”或按 `R` 顺时针旋转；点击“翻转”或按 `F` 水平翻转。变换以预览中心为锚点。
4. 按 `Esc`、单击右键或点击“完成”退出，尚未落下的预览不会改变世界。
5. 放置时使用中键或按住空格加左键平移，滚轮缩放；右键专用于完成放置。

选择另一图案时，正在跟随的预览立即切换为新图案，但已经放置的细胞保留。重叠位置采用集合合并语义，不会把已有活细胞擦除。

### 观察逻辑门（v0.6）

1. 在图案库选择名称以“逻辑 ·”开头的 NOT、AND 或 OR 对照图案。
2. 点击“放置”，将图案放在与其他滑翔机路径保持距离的位置；大型结构会自动以完整包围盒显示预览。
3. 完成放置后，方框标出的 2×2 方块是不会参与碰撞的静物输出端，标签先显示 `O=?`。点击“开始”运行到推荐代数；探针检测到完整滑翔机时锁存 `O=1`，否则锁存 `O=0`。
4. NOT 提供 2 种输入，AND 和 OR 各提供 4 种输入排列；用户可以直接对照完整真值表，并比较 `0,1` 与 `1,0` 的交换律结果。

输出标签一旦锁存就不再随普通细胞闪烁而改变。用户继续运行时，2×2 静物方块也必须保持原样；它只是输出端位置标记，逻辑值由从旁经过的滑翔机信号决定。

逻辑门对滑翔机相位和相对位置敏感。手动增删细胞、旋转、翻转或与其他图案路径重叠，都可能改变演算结果；这属于生命游戏本身的行为，而不是界面错误。

### 保存自定义图案（P1）

1. 用户暂停演化并把要保存的图案留在当前世界中。
2. 点击“保存为图案”，打开轻量对话框；对话框显示活细胞数、图案宽高和缩略预览。
3. 用户填写必填名称和可选说明，点击“保存”。保存只截取当前全部活细胞的最小包围盒，不改变世界、代数或视图。
4. 保存成功后，新图案出现在“我的图案”分组并自动成为当前选项；用户仍需点击“放置”才会替换世界。
5. 空世界时“保存为图案”禁用。运行中点击时先暂停，并保留当前代数对应的形状。

首版不提供矩形框选：这是为了避免“绘制”和“选择”两套 Canvas 手势互相冲突。保存多个分离结构时，它们之间的相对间距属于图案的一部分。

### 管理我的图案（P1）

- 预设选择框使用“内置图案”和“我的图案”两个分组；内置图案始终排在前面。
- “管理”对话框列出名称、尺寸和活细胞数，支持修改名称/说明和删除。
- 内置图案可载入后修改并“另存为”自定义图案，但不能被重命名、删除或覆盖。
- 自定义名称去除首尾空格后必须唯一。重名时不静默覆盖，而是提示用户改名或明确选择“更新现有图案”。
- 删除与更新均要求一次明确确认；取消后不改变图案库。
- 本地保存失败时保持对话框内容，显示原因和“复制图案 JSON”兜底入口，不影响当前世界。

### 导入与导出（P1）

- 导出立即下载 JSON，不离开页面。
- 导入只接受受支持版本和合法坐标；验证通过后才替换当前局面。
- 错误提示应说明原因，例如“文件不是有效 JSON”或“坐标超出棋盘范围”。

## 4. 视觉方向

建议采用“克制的科学实验台”风格：

- 深色或中性背景承托棋盘，活细胞使用高对比的单一强调色。
- 网格线清晰但不过亮；避免霓虹泛光干扰细胞边界。
- 状态数据使用等宽数字，减少代数变化时的视觉跳动。
- 卡片、圆角和阴影只用于建立层级，不做过度装饰。
- 颜色方案在实现前制作 1 张静态稿确认。

## 5. 控件状态

| 控件 | 暂停且棋盘为空 | 暂停且有内容 | 运行中 |
| --- | --- | --- | --- |
| 开始/暂停 | 开始，可用 | 开始，可用 | 暂停，可用 |
| 单步 | 可用 | 可用 | 禁用 |
| 清空 | 禁用 | 可用 | 可用，先暂停 |
| 随机 | 可用 | 可用 | 可用，先暂停 |
| 棋盘编辑 | 可用 | 可用 | 禁用 |
| 速度 | 可用 | 可用 | 可用 |
| 导入/预设 | 可用 | 可用 | 可用，先暂停 |
| 导出 | 禁用 | 可用 | 可用 |
| 保存为图案 | 禁用 | 可用 | 可用，先暂停 |
| 管理我的图案 | 无自定义图案时禁用 | 有自定义图案时可用 | 可用，不影响运行 |

## 6. 反馈与错误

- 常规状态变化在状态栏直接反馈，不频繁弹窗。
- 导入失败等需要用户注意的问题使用页面内提示，并可被屏幕阅读器读出。
- 清空确认使用原生或轻量模态框，但必须支持键盘操作和取消。
- 不使用仅靠红/绿颜色区分的成功与失败状态。

## 7. 键盘与可访问性

- `Space`：轻点开始/暂停；按住并拖动棋盘时平移。
- `ArrowRight`：暂停状态下单步。
- `C`：清空；有内容时仍遵循确认规则。
- `0`：适应当前图案或回到原点。
- `R`：放置模式中顺时针旋转预览。
- `F`：放置模式中水平翻转预览。
- `Esc`：完成并退出放置模式。
- 快捷键在输入框或选择框聚焦时不触发。
- Canvas 若用于渲染，必须提供可访问名称和键盘等效操作说明；主要控制不放在 Canvas 内。
- 焦点顺序与视觉顺序一致。

## 8. 已确认的设计决策

- 运行时禁止编辑，并给出先暂停的反馈。
- 清空使用可撤销提示。
- 手机端优先完整展示棋盘，不使用页面级横向滚动。
- 采用克制的深色科学实验台风格，以青绿色作为活细胞强调色。
- 无限世界没有可见边框终点；视图状态显示倍率和视野中心坐标。
