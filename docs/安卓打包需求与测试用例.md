# 安卓打包需求与测试用例

把康威生命游戏打包为可安装的安卓 APK：极简 WebView 外壳 + 内置网页资源，
云端构建 debug 包，完全离线可用。本文定义验收标准与用例，实施步骤见
[安卓打包实施计划](./安卓打包实施计划.md)。

## 1. 目标与范围

| 项 | 内容 |
|---|---|
| 目标 | 手机/平板可安装的 APK，玩法与网页端一致，无需网络 |
| 包名 | `com.xiaoxuhui.conway` |
| 应用名 | 康威生命游戏 |
| minSdk / targetSdk | 24（Android 7.0）/ 34 |
| 版本 | versionName `0.16.0`，versionCode `1` |
| 签名 | debug（首版直接安装，不折腾正式签名） |
| 分发 | GitHub Release 挂载 APK |

**不在本期范围**：纯血鸿蒙 NEXT（需 HAP）、原生能力（相机/推送）、正式签名上架。

## 2. 网页形态判定

入口 `index.html` 以相对路径引用 15 个 `scripts/*.js` 与 `styles/main.css`，
属于 **B 类：多文件静态站**。因此同步策略为：

```
index.html → assets/index.html
scripts/   → assets/scripts/
styles/    → assets/styles/
```

入口页与 `MainActivity.ASSET_FILE` 必须同为 `index.html`。

## 3. 能力适配清单

| 网页能力 | WebView 表现 | 外壳处理 | 涉及位置 |
|---|---|---|---|
| `localStorage`（我的函数、自定义图案） | 需开启 domStorage | `domStorageEnabled = true` + 固定 https 域保证 origin 稳定 | MainActivity |
| `Blob` + `<a download>` 导出 | **静默失败** | 注入脚本劫持 click → 取 blob 文本 → JS 桥写系统下载目录 | 3 处导出 |
| `<input type="file">` 导入 | 无反应 | 实现 `onShowFileChooser` | 3 处导入 |
| 触摸点击放置图案 | 正常（Pointer Events） | 无需改动 | — |
| HTML5 拖放 | 触摸端不触发 | **本期不改**（属独立改造） | — |

**三处导出**（均走 `ConwayAndroid.saveFile`）：

1. `exportWorld()` → `life-infinite-generation-<generation>.json`
2. `exportPatternLibrary()` → `conway-life-patterns-<date>.json`
3. `exportLogicFunctionLibrary()` → `conway-life-functions-<date>.json`

## 4. 验收用例

### 4.1 构建与结构（无需真机）

| 编号 | 用例 | 预期 |
|---|---|---|
| U01 | `npm run check:android` | assets 与源逐字节一致，退出码 0 |
| U02 | `npm test` 中的安卓结构断言 | 包名/命名空间/SDK/版本/应用名/桥名全部匹配 |
| U03 | APK 内 `assets/index.html` 与仓库 `index.html` | `cmp` 通过，字节一致 |
| U04 | CI 构建 | Android APK workflow 通过，产出 `app-debug.apk` |

### 4.2 安装与启动

| 编号 | 用例 | 预期 |
|---|---|---|
| U05 | 安装 APK | 允许「未知来源」后可正常安装，无失败提示 |
| U06 | 首次启动 | 直接进入棋盘界面，无白屏、无黑屏闪动 |
| U07 | 飞行模式启动 | 可正常启动并完整游玩（全离线） |
| U08 | 桌面图标 | 显示滑翔机图标与「康威生命游戏」名称 |
| U09 | 权限检查 | 系统设置中无任何权限申请（尤其无网络权限） |

### 4.3 功能一致性

| 编号 | 用例 | 预期 |
|---|---|---|
| U10 | 棋盘渲染 | 网格、配色与网页端一致（深色墨绿主题） |
| U11 | 演化控制 | 开始/暂停、单步、速度档位、清空、随机均可用 |
| U12 | 放置图案 | 点「放置」进入放置模式，触摸画布可落下图案 |
| U13 | 数据持久化 | 保存「我的函数」与「自定义图案」后杀进程重进，仍在 |
| U14 | 导出 JSON | 点导出后**不下载**，改为提示「已保存到下载/…」，文件可在系统下载目录找到且 JSON 合法 |
| U15 | 导入 JSON | 点导入弹出系统文件选择器，选中后能预览摘要并确认导入 |

### 4.4 屏幕与交互

| 编号 | 用例 | 预期 |
|---|---|---|
| U16 | 旋转屏幕 | 不重建 Activity，演化状态与视图不丢失 |
| U17 | 手机竖屏 | 控件不重叠、不被键盘遮挡，画布可正常操作 |
| U18 | 平板横屏 | 布局正常，画布充分利用空间 |
| U19 | 刘海/系统栏 | 顶部不被状态栏或挖孔遮挡，底部不被导航栏遮挡 |
| U20 | 返回键 | 优先回退网页历史；无历史时退出应用 |

## 5. 通过标准

- U01–U04 必须全过（构建期守门，CI 自动执行）。
- U05–U20 需真机验证，允许个别项标注为「已知限制」并说明原因。
- 已知设计取舍：导出走系统下载目录而非浏览器下载（WebView 不支持 Blob 下载），
  用户感知为「提示已保存」而非「弹出下载」。
