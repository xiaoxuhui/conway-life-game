# 需求文档

## 1. 背景

用户希望拥有一个可在本地随时打开的康威生命游戏。产品可参考现有在线模拟器的核心操作思路，但不复制其界面、视觉或代码。第一版首先追求清楚、稳定、容易玩，而不是堆叠功能。

## 2. 产品目标

1. 用户无需安装后端或注册账号，即可在本地运行。
2. 用户能在 30 秒内理解如何绘制细胞并开始演化。
3. 常用操作都能在一个页面内完成，当前状态始终可见。
4. 核心规则正确，并能用自动化测试验证。
5. 设计允许后续增加图案库、导入/导出和更大的棋盘。

## 3. 目标用户

- 想直观体验生命游戏的初学者。
- 想观察或构造经典图案的爱好者。
- 想用它进行演示或教学的用户。

## 4. 核心使用场景

### 场景 A：自由绘制

用户打开页面，点击或拖动棋盘绘制活细胞，点击“开始”，观察图案演化；可以随时暂停、单步或清空。

### 场景 B：观察经典图案

用户选择“滑翔机”等预设，图案出现在棋盘中央；用户开始运行，观察它随代数变化。

### 场景 C：保存与继续

用户导出当前局面为本地文件，之后再导入并继续观察。该场景属于 MVP 后的增强阶段。

## 5. MVP 功能需求

优先级说明：P0 为 MVP 必须完成，P1 为 MVP 稳定后补充，P2 暂不进入近期开发。

| 编号 | 优先级 | 需求 | 验收要点 |
| --- | --- | --- | --- |
| FR-01 | P0 | 显示可编辑棋盘 | 棋盘边界和每个格子清晰可辨 |
| FR-02 | P0 | 点击格子切换生/死 | 暂停时点击一次只改变目标格 |
| FR-03 | P0 | 拖动连续绘制或擦除 | 一次拖动保持同一种绘制意图，不来回翻转 |
| FR-04 | P0 | 开始与暂停 | 按钮文案和运行状态一致；重复点击不创建多个计时器 |
| FR-05 | P0 | 单步演化 | 每次操作恰好增加一代，并按 B3/S23 规则更新 |
| FR-06 | P0 | 清空棋盘 | 清空细胞并将代数重置为 0；运行中操作时先暂停 |
| FR-07 | P0 | 随机填充 | 生成适合观察的随机局面，并将代数重置为 0 |
| FR-08 | P0 | 调节速度 | 调节后下一次演化周期生效；显示直观速度值 |
| FR-09 | P0 | 显示代数与状态 | 始终显示当前代数、运行/暂停状态和活细胞数量 |
| FR-10 | P0 | 响应式布局 | 常见桌面窗口和手机竖屏均可操作，不出现页面级横向滚动 |
| FR-11 | P1 | 预设图案 | 至少包含滑翔机、闪烁器和轻量级飞船；载入后居中显示 |
| FR-12 | P1 | 导出局面 | 下载带格式版本、棋盘尺寸和活细胞坐标的 JSON 文件 |
| FR-13 | P1 | 导入局面 | 校验 JSON；错误文件显示明确提示且不破坏当前棋盘 |
| FR-14 | P1 | 键盘快捷键 | 空格开始/暂停、右方向键单步、C 清空，且不干扰表单操作 |
| FR-15 | P2 | 无限棋盘 | 支持平移、缩放和稀疏世界模型 |
| FR-16 | P2 | RLE 格式 | 导入和导出生命游戏社区常用的 RLE 格式 |

## 6. 生命游戏规则

采用标准规则 **B3/S23**：

- 死细胞恰好有 3 个活邻居时出生。
- 活细胞有 2 或 3 个活邻居时存活。
- 其他情况细胞死亡或保持死亡。
- 一代中的所有细胞必须基于同一份旧状态同时更新。

MVP 使用有限矩形棋盘，边界以外视为死亡，不首尾环绕。

## 7. 非功能需求

### 易用性

- 首屏提供一句简短操作提示，不要求先阅读说明书。
- 主操作按钮使用文字和图标（若有），不只依赖颜色表达。
- 危险程度较低的清空操作允许撤销是理想项；MVP 至少要避免误触后无提示的运行状态混乱。

### 性能

- 目标棋盘为 60 × 40 时，在主流桌面浏览器中以 10–20 代/秒运行应保持交互流畅。
- 暂停后不得残留后台演化计时器。

### 兼容与离线

- 支持近期版本的 Chrome、Edge 和 Firefox。
- 核心玩法不依赖网络、CDN、账号或远程接口。
- 不收集、不上传用户数据。

### 可访问性

- 所有按钮和控件可通过键盘聚焦。
- 焦点样式明显；文本和背景对比度达到 WCAG AA 的基本要求。
- 运行状态不能只通过颜色传达。
- 尊重 `prefers-reduced-motion`，避免不必要动画。

## 9. 暂不做的内容

- 用户账号、云同步、排行榜或社交功能。
- 后端服务和数据库。
- 复杂主题系统、音效和装饰性动画。
- 直接复刻参考网站的布局或素材。
- 在 MVP 中追求无限棋盘或超大规模模拟。

## 10. 已确认的产品决策

以下决策于 2026-08-19 经用户确认：

1. 默认棋盘为 60 × 40。
2. 默认速度为每秒 5 代。
3. 随机填充默认密度为 25%。
4. 首版采用克制的“科学实验台”视觉风格。
5. 清空采用可撤销提示，不使用确认弹窗；撤销恢复清空前的局面和代数。
6. 运行时禁止直接编辑棋盘，用户需先暂停。
7. 手机端优先完整展示棋盘；在保证控件可操作的前提下自适应缩放。
