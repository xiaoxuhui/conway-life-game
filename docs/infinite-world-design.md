# 无限世界设计方案

## 1. 目标

把现有 60 × 40 固定数组升级为实际使用上无边界的康威生命世界，同时保留离线、零后端、可直接打开和规则可测试的特点。

“无限”表示：世界没有固定宽高，活细胞可以出现在正负整数坐标的任意方向；视图可以连续平移并在极宽范围内缩放。它不表示浏览器拥有无限内存或无限数值精度。

## 2. 世界模型

使用 `Set<string>` 只记录活细胞：

```text
"row,column"
"-12,480"
```

未出现在集合中的坐标均为死细胞。坐标必须是 JavaScript 安全整数，避免相邻坐标因浮点精度合并。

下一代算法：

1. 遍历每个活细胞。
2. 给它周围八个候选坐标累计邻居数。
3. 邻居数为 3 的坐标出生；邻居数为 2 且当前存活的坐标继续存活。
4. 生成新的活细胞集合。

复杂度由活细胞数量和其邻域决定，不依赖可见区域或理论地图大小。密集且无限增长的图案仍会受到设备性能和内存限制。

## 3. 相机模型

相机状态：

```js
{
  centerRow: 0,
  centerColumn: 0,
  cellSize: 16
}
```

`cellSize` 表示一个世界格对应的 CSS 像素数。内部允许约 `0.0001–1024` 像素/格的范围，相当于从一次观察数百万格到单个格子铺满多屏。界面不提供有端点的滑块，避免给用户“固定地图级别”的感觉。

滚轮缩放前先计算光标下的世界坐标，改变 `cellSize` 后反算相机中心，使该世界点留在同一屏幕位置。平移只改变相机，不改变世界数据。

## 4. 多尺度渲染

- `cellSize ≥ 6px`：绘制每格网格和完整细胞方块。
- `1px ≤ cellSize < 6px`：隐藏网格，绘制紧凑细胞方块。
- `cellSize < 1px`：每个可见活细胞至少贡献一个像素；重叠像素自然形成更亮的密度分布。
- 所有层级只绘制 Canvas 视口内的活细胞，不扫描可见范围中的死细胞。
- 原点轴线只在不会干扰图案时弱化显示，帮助用户建立方向感。

## 5. 输入状态机

鼠标：

- 左键：绘制或擦除。
- 中键/右键：平移。
- `Space + 左键`：平移；若空格按下到释放之间没有拖动，则执行开始/暂停。
- 滚轮：光标中心缩放。

触屏：

- 单指：绘制或擦除。
- 第二根手指按下：取消本次单指绘制，进入双指手势。
- 双指质心变化控制平移，指间距离变化控制缩放。

绘制与平移使用独立状态，任何手势在结束或取消时都必须释放指针捕获并清理临时状态。

## 6. 视图适应

“适应图案”读取全部活细胞包围盒：

- 空世界：中心回到 `(0, 0)`，恢复默认倍率。
- 单个或很小图案：居中并采用舒适倍率，不无限放大。
- 大图案：在 Canvas 四周保留约 12% 边距后完整显示。

随机世界和预设图案以当前视野中心为放置中心，不再依赖固定棋盘中心。

## 7. 存档兼容

JSON v2：

```json
{
  "format": "conway-life-game",
  "version": 2,
  "generation": 42,
  "alive": [[-1, 0], [0, 1], [1, -1]],
  "view": { "centerRow": 0, "centerColumn": 0, "cellSize": 16 }
}
```

- v2 使用有符号世界坐标，并可保存视图。
- v1 的 `rows`、`columns` 和非负坐标仍可导入；细胞坐标原样迁移，视图以旧棋盘中心初始化。
- 导入先完整校验，再一次性替换当前状态。
- v2 导出不再写固定行列数。

## 8. 模块边界

- `life-engine.js`：稀疏世界、B3/S23、坐标校验、v1/v2 序列化。
- `renderer.js`：相机、坐标变换、多尺度 Canvas 绘制和视图适应计算。
- `app.js`：运行状态、输入状态机、控制按钮、计时器和文件交互。
- `presets.js`：保持相对坐标数据不变。

## 9. 测试策略

- 负坐标和远离原点的静物、振荡器、滑翔机。
- 大坐标相邻计算不串格。
- 空世界和重复坐标。
- v2 往返、非法坐标、v1 迁移。
- 光标中心缩放前后世界坐标误差。
- 平移只改变相机，绘制只改变世界。
- 轻点空格与空格拖动互不误触。
- 鼠标、触屏、运行中导航、极端倍率、桌面与手机布局。

## 10. 风险与限制

- 生命数量快速爆炸时，稀疏算法仍可能变慢；不得通过遗漏细胞来假装保持速度。
- JavaScript 安全整数是坐标硬边界；对实际交互而言范围极大，但不是数学上的真正无限。
- 极度缩小时多个细胞落在同一像素，只能表达密度，不能逐格辨认。
- 浏览器自动化不能完全等价于真实双指触屏，需保留真实设备补测项。
