# 安卓打包实施计划

分阶段推进，每阶段一个 commit，便于回滚与 review。
验收标准见 [安卓打包需求与测试用例](./安卓打包需求与测试用例.md)。

技术版本组合**固定不变**（偏离易踩坑）：
AGP 8.5.2 + Gradle 8.7 + JDK 17 + compileSdk/targetSdk 34 + minSdk 24 +
androidx.webkit 1.11.0。

## 阶段 0：准备与形态分类

- [x] 确认网页形态：B 类多文件静态站（`index.html` + `scripts/` + `styles/`）
- [x] 确认无打包器产物，无需改 `base` 路径
- [x] 排查能力清单：localStorage、3 处 Blob 导出、3 处 file 导入
- [x] 基线测试通过（113/113）
- [x] 基于 main 切出分支 `feat-android-apk`

> ⚠️ **环境注意**：本机沙箱环境**无法创建含 `/` 的分支名**（`git switch -c feat/android-apk`
> 会静默失败：HEAD 指向了 `refs/heads/feat/android-apk`，但 ref 文件不生成）。
> 因此分支名改用 `feat-android-apk`。切分支后必须用 `git branch --show-current` 复核。

## 风险与已知取舍

| 项 | 说明 |
|---|---|
| 导出交互差异 | WebView 不支持 Blob 下载，改由 JS 桥写系统下载目录，提示语为「已保存到…」 |
| HTML5 拖放 | 触摸端不触发，属独立改造，不混入本次打包 |
| assets 含工具脚本 | 同步整个 `scripts/` 目录，会把 `serve-static.js` 等一并带入（约几 KB，无功能影响） |
| 分支名限制 | 沙箱环境不支持含 `/` 的分支名，统一用 `feat-android-apk` |
