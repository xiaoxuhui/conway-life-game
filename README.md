# 康威生命游戏

[![CI](https://github.com/xiaoxuhui/conway-life-game/actions/workflows/test.yml/badge.svg)](https://github.com/xiaoxuhui/conway-life-game/actions/workflows/test.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

一个使用原生 HTML、CSS 和 JavaScript 实现的本地康威生命游戏，支持无边界世界、自由平移和连续缩放。

GitHub：<https://github.com/xiaoxuhui/conway-life-game>
在线演示：<https://xiaoxuhui.github.io/conway-life-game/>

![康威生命游戏界面截图](docs/screenshot.png)

> 当前状态：v0.15.0 已完成，包含无限世界、高速批量演化、带多布局与可调通道的任意嵌套逻辑、可嵌套调用的参数函数库、24 种经典内置图案和自定义图案库。

## 项目目标

- 双击 `index.html` 即可使用，不依赖后端服务。
- 让第一次接触生命游戏的人也能直观地绘制、运行和理解演化过程。
- 保持代码和交互简单，为后续添加更多图案与实验功能留出空间。

## 功能

- 点击或拖动棋盘绘制、擦除活细胞。
- 使用中键、右键或按住空格拖动画布；滚轮以光标为中心连续缩放。
- 触屏单指绘制、双指平移缩放；缩放跨度从世界全景到单格细节。
- 开始/暂停、单步、清空与撤销、25% 密度随机填充。
- 直接输入 1–1000 代/秒的目标速度，支持键盘上下键调节并在运行中即时生效；高速时每帧批量演化多代、只渲染最终状态，并显示机器实际达到的代/秒。
- 24 种经典内置图案：滑翔机、静物、振荡器、飞船、长寿型初始图案、滑翔机枪，以及 NOT、AND、OR 逻辑门的完整 10 行真值表。
- 逻辑门名称直接显示输入与输出；AND、OR 的两路输入纵向错开 1 格、横向相隔 42 格（偶数）。输出端是不会被碰撞破坏的 2×2 静物方块，旁边的 `O=?` 会在完整滑翔机经过探针时锁存为 `O=1`，否则锁存为 `O=0`。
- 可输入 `1 AND 0`、`NOT(AND(0,0))` 等逻辑代码，也支持 `与/或/非`、`&&/||/!` 和末尾变量赋值；例如 `AND(A,B),A=1,B=0`。
- 支持最多 8 层函数嵌套；例如 `NOT(AND(0,0))` 会删除 NOT 自带的输入发生器，把 AND 的实际输出线路接入 NOT，最终由根门探针读取 `O=1`。
- 同一个 AND/OR 的两路都可以连接子门的实际输出；例如 `OR(AND(A,NOT(B)),AND(NOT(A),B)),A=1,B=1` 会生成 5 个门和 4 条真实滑翔机线路，而不是直接写入预先算好的答案。
- 可把当前有效逻辑代码命名保存到“我的函数”，刷新后重新载入；管理窗口支持重命名、修改代码和二次确认删除，函数数据与图案库独立保存。
- 函数会自动识别 `A、B` 等变量并显示独立的 0/1 输入；载入时才把当前输入组装成完整代码。旧版已保存函数的末尾赋值会自动迁移为默认输入。
- 英文函数名称可以直接写进其他表达式；例如保存 `XOR` 后可运行 `NOT(XOR(1,0))`，保存函数也可以继续调用其他保存函数。
- 函数名支持数字和下划线；`GF_2(1,0,1,0)` 这类短调用即使内部嵌套展开超过 200 字符也能运行，同时保留 5000 字符的展开安全上限。
- 保存函数可以混用 `AND(A,B)` 与 `(A AND B)` 两种写法并使用括号分组；优先级为 `NOT`、`AND`、`OR`。缺少被调用函数时会直接提示具体调用名。
- 大型嵌套结构会分时间片完成布线与安全验证，页面显示验证进度并保持可操作；生成按钮会变为“取消生成”，可随时停止且不会修改当前世界。
- 安全线路验证使用更大的计算时间片并复用已证明为 p30 的枪体参考相位；5 门基准约由 8.5 秒缩短到 5.7 秒，完整验证时域保持不变。
- 安全区比较只扫描预期活细胞和当前世界中的活细胞，不再逐代遍历矩形内大量空格；同一 5 门基准进一步缩短到约 3.9 秒。
- 每个嵌套候选都会逐代验证所有输入枪和门体枪的占用区；发现外来滑翔机侵入会自动换用更大线路间距，所有候选都不安全时拒绝生成。
- 超过 5 个基础门的大型函数会搜索多种子树转置布局；页面显示当前布局、间距与验证代数。用户给出的 15 门组合现可生成 14 条真实线路并通过 4236 代安全验证。
- 安全候选同时搜索 20、40、80 个 p30 周期的分支通道间隔；线路撞到无关门体时会整体拉开该子分支，并在组合完成后统一根输出方向。
- 图案放置前显示半透明预览；左键拖动后松开即可落下，并可连续追加多个图案。
- 放置模式支持按钮或 `R` 旋转、`F` 翻转，`Esc`、右键或“完成”退出。
- 可将当前全部活细胞保存为“我的图案”，刷新后继续使用，并支持重命名、更新和确认删除。
- 带版本校验的 JSON v2 导入/导出，可保留负坐标和当前视图，并兼容 v1 存档。
- `空格` 点击开始/暂停、按住拖动平移；`→` 单步、`C` 清空、`0` 适应图案；放置时用 `R` 旋转、`F` 翻转、`Esc` 完成。
- 响应式桌面和手机布局，核心玩法完全离线。

## 本地运行

最简单的方式是在文件管理器中双击 `index.html`。应用不使用 ES Module、远程资源、后端或数据库。

开发调试时也可以在仓库目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。

## 自动化测试

开发工具要求 Node.js 20.19 或更高版本。应用运行时仍然零依赖；仓库只安装 ESLint 作为开发依赖：

```powershell
npm ci
npm run check
npm run lint
npm test
```

也可以直接执行：

```powershell
node --test
```

当前测试覆盖 B3/S23 规则、负坐标和百万格外演化、稀疏世界、相机坐标、光标锚定缩放、v1/v2 存档迁移、自定义图案归一化与本地持久化、逻辑门真值、预设数据和离线资源结构。

## “无限”的边界

世界使用有符号安全整数坐标和稀疏活细胞集合，不存在固定宽高或可撞到的棋盘边框。缩放范围也足以覆盖日常使用中的宏观观察与单格细节；实际容量仍受浏览器内存、浮点精度和屏幕像素限制。生命数量非常大时，每一代的计算会相应变慢。

## 自定义图案的保存位置

“我的图案”只保存在当前浏览器的本地存储中，不会上传网络。直接双击 `index.html` 与通过 `http://127.0.0.1:端口` 打开时通常属于不同的浏览器存储来源，因此两种打开方式的图案库可能不互通。首版保存当前世界中的全部活细胞，不提供局部框选。
